## 2. 调查方法

1. **静态字符串与资源表**：`strings -a -n 4` 提取 296,569 条字符串；其中约 105k–130k 行区间是应用自己的 UI 字符串表（动作名、动作说明、设置键、错误文案）。另从 `:/icons/*.svg`、`:/cursors/*.svg` 路径统计出 108 个内嵌 SVG 图标与 7 个光标。
2. **运行观察**：在 macOS 上启动原版 PureRef，通过辅助功能（System Events）读取完整菜单栏与子菜单；用截图逐页记录 7 个设置分页、快捷键表（17 屏）、右键菜单、帮助浮层、空场景、标题栏、导出对话框。
3. **行为验证**：向画布粘贴图片、执行保存、观察自动保存与恢复、检查 `.pur` 文件头；用真实鼠标键盘事件测试滑动、缩放、框选、右键拖拽移动窗口等。
4. **持久化格式**：保存 `.pur` 后用十六进制解析头部，确认版本串、场景 GUID、长度前缀与图片段（内嵌 JPEG 缩略图 + 原始图片字节）。

不涉及破解授权、绕过购买流程或提取登录逻辑；纯功能行为与界面规格复原。

## 4. `.pur` 文件头解析（`/tmp/test.pur`，单图场景）

```
偏移 0x00  uint32 BE 0x00000006      // 字符串字节长度
偏移 0x04  UTF-16BE  "2.1"           // 文件格式大版本
偏移 0x0A  uint32 BE 0x00000000      // 标志位
偏移 0x0E  uint32 BE 0x0000000A
偏移 0x12  UTF-16BE  "2.1.3"         // 应用版本
偏移 0x1C  uint32 BE 0x00000040      // 32 字符 = 64 字节
偏移 0x20  UTF-16BE  "6a1bb0d1…84bb" // 32 位十六进制场景 ID
偏移 0x60  uint32 BE 0x000019EF      // 6639
偏移 0x64  JPEG 数据（FFD8…）        // 场景缩略图
...
          图片段、元数据段、校验和……
```

结论：二进制容器，**大端长度前缀 + 版本串 + 场景 GUID + 分段数据 + 校验和**，缩略图与图片以原始格式内嵌。MuseNex 参考板不复刻该格式，改用自描述的 `PRCYQ1` 容器（JSON 头 + 图片二进制段 + 绝对偏移），设计目标一致：单文件、可嵌图、可校验、可恢复。

## 7. 与 PureRef 的已知差异（诚实清单）

1. **文件格式**：不读写 `.pur`；自有 `.prcyq`。打开 `.pur` 会给出明确提示。
2. **Overlay selection**：原版为每张图独立窗口；本版本实现为“单窗口无背景叠加态”的近似。
3. **Always on top of（指定应用之上）**：近似为“始终置顶”。
4. **Always on bottom**：以取消置顶近似（macOS 下未真正置底）。
5. **全局快捷键**：未实现（需要辅助功能权限与系统级注册）。
6. **视频解码 / 多帧帧条**：GIF/WebP 动图可播放（浏览器解码），未实现视频文件与逐帧拖动条。
7. **性能模式与自动优化规则**：设置项与手动优化已实现；磁盘缓存/CPU 分配为记录型设置，未改变实际渲染管线。
8. **颜色配置 / HDR**：未实现屏幕色彩配置转换（设置项为记录型）。
9. **语言**：仅简体中文界面（原版 10+ 语言；保留 Language 设置位置）。
10. **更新/遥测/登录**：全部移除（符合需求）。
11. **Overlay 模式添加图片限制**、**多窗口间的本地 socket 单实例**：简化为“同一路径聚焦已有窗口”（通过 Electron singleInstanceLock 提示）。
12. **导出 PSD / 原生格式保留**：导出按扩展名支持 PNG/JPEG/WebP；无 PSD 导出。
13. **原版 `.pur` 的 Tags、自动恢复分片、旧格式迁移**：未实现（自有格式无此历史包袱）。

```bash
# 1. 获取样本（官网免费下载，需同意许可）
#    得到 PureRef-2.1.3_x64.dmg，挂载后复制 PureRef.app

grep -oE ':/icons/[A-Za-z0-9_]+\.svg' pureref.strings | sort -u

# 3. 动态证据：启动原版，macOS 辅助功能读取菜单
osascript -e 'tell application "System Events" to tell process "PureRef" to get name of every menu bar item of menu bar 1'

# 4. 保存样本场景，查看文件头
xxd -l 160 ~/Desktop/test.pur
```
